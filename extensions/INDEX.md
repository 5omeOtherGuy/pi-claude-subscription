# extensions index

- `pi-claude-subscription/index.ts`: the Pi extension (Pi labels it by this folder name), discovered through `package.json` `pi.extensions`. It resolves the host transport before registering, then registers only `{ api: "anthropic-messages", streamSimple }` on Pi's built-in `anthropic` provider; login, refresh, models and API-key auth stay Pi's. At `session_start` it warns if a saved `claude-subscription` selection is found (it changes nothing) or if another extension's `anthropic` transport has replaced this one. It also registers `/claude-subscription-status`. It never unregisters a provider.
